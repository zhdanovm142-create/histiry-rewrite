# Правки раздела 1.1

- В репозитории оставлен только текстовый формат главы: `Вот отредактированный текст главы (1).txt`.
- Удалены `.docx`-файлы из состава PR, чтобы исключить бинарные диффы и ошибки просмотра в web UI.
- В текстовый файл добавлена явная разметка блоков для последующей автоматической сборки в Word-документ:
  - `[TITLE]` — заголовок документа;
  - `[HEADING2]`/`[HEADING3]` — заголовки разделов;
  - `[PARA]` — основной абзац.
- Содержательная логика раздела 1.1 сохранена: институциональные изменения → кадровые последствия → нормативные акты.
- Сохранены новые аналитические мини-блоки (ведомственная подчиненность, влияние судебной реформы 1864 г., кадровая динамика) и целевой KPI по снижению самоцитирования.
